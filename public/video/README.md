# Видео лендинга

Сейчас в `db.json` прописаны **временные ролики с Pexels** (прямые ссылки на CDN),
чтобы секции не пустовали до получения материалов по макету:

| Секция                          | Временная ссылка                                                                 |
|---------------------------------|----------------------------------------------------------------------------------|
| Первый экран (`homeHero.video`) | `https://videos.pexels.com/video-files/9239575/9239575-hd_1920_1080_30fps.mp4` (~7 МБ) |
| Секция «Видео» (`videoUnit.video`) | `https://videos.pexels.com/video-files/6272118/6272118-hd_1920_1080_30fps.mp4` (~10 МБ) |

Источники: [Driving a 4x4 Offroad](https://www.pexels.com/video/driving-a-4x4-offroad-9239575/),
[Off Road Car Driving on the Mud](https://www.pexels.com/video/off-road-car-driving-on-the-mud-6272118/) —
Pexels License, бесплатно для коммерческого использования, но это **заглушки**, не техника заказчика.

## Как поменять на свои

Положить файлы сюда и вернуть в `db.json` локальные пути — вёрстку править не нужно:

| Файл       | Где используется                    | Что должно быть в кадре                          |
|------------|-------------------------------------|--------------------------------------------------|
| `hero.mp4` | Первый экран (фон, autoplay + loop) | Общий план: вездеход в движении по бездорожью     |
| `test.mp4` | Секция «Видео» (по центру страницы) | Крупные планы: болото, брод, подъём               |

Требования:

- Формат **mp4 (H.264)**, звук можно оставить — оба ролика стартуют без звука.
- `hero.mp4` — без резких склеек, желательно 10–20 с, вес до ~8 МБ: он грузится на первом экране.
- Соотношение сторон: hero — любое (кадрируется по `object-fit: cover`), test — ближе к 16:9.
- Постеры-заглушки лежат в `public/img/home/hero-poster.svg` и `public/img/video/poster.svg`;
  замените их на кадры из роликов, когда те появятся.
